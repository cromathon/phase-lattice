# Phase Lattice

Discrete signal propagation over a binary state space.

## Setup

Requires Python 3.

## Run

From the project root:

```
PYTHONPATH=. python3 experiments/demo.py
```

Alternate run:

```
PYTHONPATH=. python3 experiments/demo_cancel.py
```

## Notes

* Uses phase-weighted propagation
* Demonstrates non-uniform signal evolution
* No external dependencies
